# 프리브 설계 문서

실행·설치 방법과 현재 검증 범위는 저장소 루트의 [README](../README.md)를 확인하세요. 아래 문서는 기능과 설계의 참고 자료이며, 실제 구현 상태는 소스와 루트 README를 기준으로 합니다.

- [기능 설계](development-spec.md): 서비스 흐름과 주요 기능.
- [인증 설계](authentication-spec.md): Google 로그인, 차량 QR/코드 연결, 세션과 권한.
- [프로젝트 구조](project-structure.md): 앱·서버 경계와 디렉터리 구성.
- [디자인 가이드](design-guide.md): 색상·타이포그래피·반응형 화면 기준.
- [디자인 토큰](design-tokens.json): 앱 공통 색상·크기·간격.
- [디자인 참고 화면](design-preview.html): 휴대폰·차량 화면 시안.

시안은 디자인 참고 자료이며 실제 차량 하드웨어 검증이나 주행 중 사용 인증을 의미하지 않습니다.
